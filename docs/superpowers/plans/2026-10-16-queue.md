# Per-folder queue and bot-side configuration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `folders.yaml` and one-digest-per-run with folders configured through `/folder` in the bot chat and a persistent per-folder queue that always delivers the best-scored posts first.

**Architecture:** Folders and their tuning live in a `folders` table; every fetch upserts scored posts into a `queue` table keyed `(folder_id, channel_id, msg_id)`. A 60 s ticker runs due folders with a window anchored to the slot time. Batches drain the queue top by score; the read-marker auto-next, pacing and the Next button are unchanged in behaviour but keyed by folder, and exactly one Next button exists, on the last bot message (fetch note or footer).

**Tech Stack:** Python 3.12, Telethon 1.45.0, aiosqlite, pydantic 2 + pydantic-settings, loguru, click; uv, ruff, mypy (strict), pytest + pytest-asyncio. apscheduler and PyYAML are removed.

**Spec:** `docs/superpowers/specs/2026-10-16-queue-design.md` (the parts of `docs/superpowers/specs/2026-10-15-telegrief-design.md` it does not supersede still apply).

## Global Constraints

- Dependency pins stay as in `pyproject.toml`; this plan only removes `apscheduler`, `pyyaml` and `types-pyyaml` (Task 8). Run `uv lock` after editing `pyproject.toml`.
- All datetimes are timezone-aware UTC, stored as ISO strings (`datetime.isoformat()`), so string comparison in SQL orders them correctly.
- Defaults copied from the spec: `min_age_h=24`, `period_h=24`, `batch_size=10`, `scoring=per_view`, `min_denominator=200`, `max_items=1000`, `max_age_d=7`. Validation: `min_age_h >= 0`, `period_h >= 1`, `batch_size >= 1`, `min_denominator >= 1`, `max_items >= 1`, `max_age_d >= 1`, and `max_age_d * 24 > min_age_h + period_h`.
- Message texts, exactly: fetch note `📥 +{fetch_added} · {pending} queued`; footer lines `#{n} · {score} · {engagement}{👍|↗️} / {views}👁 · {channel}` then `queued {pending}` or `✅ queue empty`; button label `Next {batch_size}`, callback data `next:{folder_id}`. Every message into a digest channel is silent, HTML, no link preview (link fallbacks keep the preview).
- Exactly one Next button per folder, on the most recent note or footer; posting either edits the previous holder without a button first.
- Scheduled fetch window: `[slot − (min_age_h + period_h), slot − min_age_h)` where `slot` is the latest `next_run_at + k·period_h <= now`. `/run` uses `now`. `next_run_at` advances to `slot + period_h` whether or not the fetch succeeded.
- Scheduled-fetch failures DM the owner only when the error text differs from the folder's `last_error`; a success clears it. Manual `/run` never DMs.
- Commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Before every commit run `./check.sh lint` then the checks named in the task. Code blocks in this plan may exceed 100 columns; `ruff format` rewraps them.

```python
class FolderConfig(BaseModel):
    """Per-folder tuning, editable through /folder."""

    model_config = ConfigDict(extra="forbid")

    min_age_h: int = Field(default=24, ge=0)
    period_h: int = Field(default=24, ge=1)
    batch_size: int = Field(default=10, ge=1)
    scoring: Scoring = "per_view"
    min_denominator: int = Field(default=200, ge=1)
    max_items: int = Field(default=1000, ge=1)
    max_age_d: int = Field(default=7, ge=1)

    @model_validator(mode="after")
    def _max_age_covers_window(self) -> FolderConfig:
        if self.max_age_d * 24 <= self.min_age_h + self.period_h:
            raise ValueError("max_age (days) must exceed min_age + period (hours)")
        return self

    def window(self, at: datetime) -> tuple[datetime, datetime]:
        """Half-open fetch window ``[at - (min_age + period), at - min_age)``."""
        return (
            at - timedelta(hours=self.min_age_h + self.period_h),
            at - timedelta(hours=self.min_age_h),
        )
```

```python
from .models import ChannelInfo, FolderConfig, Post, ScoredPost, Scoring

Strategy = Callable[[int, int, int, FolderConfig], float]


def engagement(post: Post, channel: ChannelInfo) -> int:
    """Reactions normally; forwards for channels that have reactions disabled."""
    return post.reactions if channel.reactions_enabled else post.forwards


def _raw(e: int, views: int, subscribers: int, cfg: FolderConfig) -> float:
    return float(e)


def _per_subscriber(e: int, views: int, subscribers: int, cfg: FolderConfig) -> float:
    return e / max(subscribers, cfg.min_denominator) * 1000


def _per_view(e: int, views: int, subscribers: int, cfg: FolderConfig) -> float:
    return e / max(views, cfg.min_denominator)


STRATEGIES: dict[Scoring, Strategy] = {
    "raw": _raw,
    "per_subscriber": _per_subscriber,
    "per_view": _per_view,
}


def score(e: int, views: int, subscribers: int, cfg: FolderConfig) -> float:
    """Score one post from its engagement, views and the channel's subscriber count."""
    return STRATEGIES[cfg.scoring](e, views, subscribers, cfg)


def rank(
    posts: Iterable[Post], channels: dict[int, ChannelInfo], cfg: FolderConfig
) -> list[ScoredPost]:
    """Score, drop zero-engagement posts, sort best first."""
    scored: list[ScoredPost] = []
    for post in posts:
        channel = channels.get(post.channel_id)
        if channel is None:
            continue
        e = engagement(post, channel)
        if e <= 0:
            continue
        scored.append(ScoredPost(post, channel, e, score(e, post.views, channel.subscribers, cfg)))
    scored.sort(key=lambda s: (-s.score, -s.engagement, s.post.date))
    return scored
```

```sql
CREATE TABLE queue (
    folder_id INTEGER NOT NULL REFERENCES folders (id) ON DELETE CASCADE,
    channel_id INTEGER NOT NULL,
    msg_id INTEGER NOT NULL,
    msg_ids TEXT NOT NULL,
    date TEXT NOT NULL,
    engagement INTEGER NOT NULL,
```

```python
"""Queue lifecycle: fetch into the queue, send batches, auto-next on read, manual next."""

from __future__ import annotations

import asyncio
import math
from collections.abc import Awaitable, Callable
from datetime import UTC, datetime, timedelta
from typing import TYPE_CHECKING

from loguru import logger

from .collector import Collector, digest_targets
from .config import Settings
from .delivery import Deliverer, render_fetch_note, render_footer
from .models import ChannelInfo, Folder, ItemState, QueueItem
from .scoring import rank, score
from .targets import TargetResolver
from .tg.protocols import (
    BotGateway,
    ChannelUnavailable,
    GatewayError,
    SessionDead,
    TargetUnavailable,
    UserGateway,
)

if TYPE_CHECKING:
    from .storage import Storage

Deferrer = Callable[[float, Callable[[], Awaitable[None]]], None]


def _asyncio_defer(delay: float, callback: Callable[[], Awaitable[None]]) -> None:
    loop = asyncio.get_running_loop()
    loop.call_later(delay, lambda: asyncio.ensure_future(callback()))


def _utcnow() -> datetime:
    return datetime.now(UTC)


class DigestService:
    """Per-folder queue: fetches add posts, batches drain the best ones into the digest channel.

    One lock per folder serialises fetch, send_batch and rescore. ``fetch`` sends the first
    batch from inside its lock through ``_send_batch``; everything else goes through
    ``send_batch``.
    """

    def __init__(
        self,
        *,
        user: UserGateway,
        bot: BotGateway,
        storage: Storage,
        collector: Collector,
        targets: TargetResolver,
        deliverer: Deliverer,
        settings: Settings,
        clock: Callable[[], datetime] = _utcnow,
        defer: Deferrer = _asyncio_defer,
        on_fatal: Callable[[Exception], None] | None = None,
    ) -> None:
        self._user = user
        self._bot = bot
        self._storage = storage
        self._collector = collector
        self._targets = targets
        self._deliverer = deliverer
        self._settings = settings
        self._clock = clock
        self._defer = defer
        self._on_fatal = on_fatal
        self._locks: dict[int, asyncio.Lock] = {}
        self._rechecks: set[int] = set()

    def _lock(self, folder_id: int) -> asyncio.Lock:
        return self._locks.setdefault(folder_id, asyncio.Lock())

    def _fatal(self, exc: Exception) -> None:
        logger.critical("user session is dead: {}", exc)
        if self._on_fatal is not None:
            self._on_fatal(exc)

    def bind(self) -> None:
        self._user.on_channel_read(self.on_read)
        self._bot.on_next_button(self.on_next_button)

    async def _name(self, folder_id: int) -> str:
        folder = await self._storage.get_folder(folder_id)
        return folder.name if folder is not None else f"folder {folder_id}"

    # ---- fetch ---------------------------------------------------------------

    async def fetch_all(self, from_h: int | None = None, to_h: int | None = None) -> list[str]:
        return [
            await self.fetch(f.id, from_h=from_h, to_h=to_h)
            for f in await self._storage.list_folders()
        ]

    async def fetch(
        self,
        folder_id: int,
        *,
        at: datetime | None = None,
        from_h: int | None = None,
        to_h: int | None = None,
        scheduled: bool = False,
    ) -> str:
        """Collect one window into the folder's queue; post the note; maybe send a batch.

        ``at`` is the reference time of the window (the slot time for scheduled runs,
        now otherwise); ``from_h`` / ``to_h`` override the bounds, in hours before now.
        Returns a one-line result for the owner.
        """
        async with self._lock(folder_id):
            return await self._fetch(folder_id, at, from_h, to_h, scheduled)

    async def _fetch(
        self,
        folder_id: int,
        at: datetime | None,
        from_h: int | None,
        to_h: int | None,
        scheduled: bool,
    ) -> str:
        folder = await self._storage.get_folder(folder_id)
        if folder is None:
            return f"❌ unknown folder id {folder_id}"
        cfg = folder.config
        now = self._clock()
        start, end = cfg.window(at if at is not None else now)
        if from_h is not None:
            start = now - timedelta(hours=from_h)
        if to_h is not None:
            end = now - timedelta(hours=to_h)
        if start >= end:
            return f"❌ {folder.name}: empty window"
        try:
            target = await self._targets.resolve(folder.name, now)
            exclude = await digest_targets(self._storage)
            collected = await self._collector.collect(folder.name, start, end, now, exclude=exclude)
            scored = rank(collected.posts, collected.channels, cfg)
            added = await self._storage.enqueue(folder.id, scored, now)
            await self._storage.prune(folder.id, cfg, now)
            pending = await self._storage.count_pending(folder.id)
            folder.last_fetch_at = now
            folder.last_error = None
            await self._storage.update_folder_state(folder)
            await self._post_note(folder, target, added, pending)
            await self._kick(folder, target, now)
        except SessionDead as exc:
            message = f"💀 {folder.name}: user session dead, run `telegrief login`: {exc}"
            await self._bot.send_owner(message)
            self._fatal(exc)
            return message
        except Exception as exc:
            logger.exception("folder {}: fetch failed", folder.name)
            message = f"❌ {folder.name}: {exc}"
            await self._report_failure(folder.id, str(exc), message, scheduled)
            return message
        message = f"✅ {folder.name}: +{added} · {pending} queued"
        if collected.errors:
            message += f" · ⚠️ skipped: {', '.join(collected.errors)}"
        logger.info(message)
        return message

    async def _report_failure(
        self, folder_id: int, error: str, message: str, scheduled: bool
    ) -> None:
        """Scheduled runs DM the owner once per distinct error; manual runs only reply."""
        if not scheduled:
            return
        folder = await self._storage.get_folder(folder_id)
        if folder is None:
            return
        if error != folder.last_error:
            await self._bot.send_owner(message)
        folder.last_error = error
        await self._storage.update_folder_state(folder)

    async def _post_note(self, folder: Folder, target: int, added: int, pending: int) -> None:
        """``📥 +N · M queued``: edited in place until a batch goes out, then a new one."""
        if folder.fetch_msg_id is None and added == 0:
            return
        folder.fetch_added += added
        text = render_fetch_note(folder.fetch_added, pending)
        next_id = folder.id if pending else None
        label = f"Next {folder.config.batch_size}"
        if folder.fetch_msg_id is not None:
            try:
                await self._bot.edit_text(
                    target, folder.fetch_msg_id, text, next_id=next_id, next_label=label
                )
            except TargetUnavailable:
                raise
            except GatewayError as exc:
                logger.warning(
                    "folder {}: cannot edit fetch note {}: {}", folder.name, folder.fetch_msg_id, exc
                )
            else:
                self._hold_button(folder, folder.fetch_msg_id, text, next_id)
                await self._storage.update_folder_state(folder)
                return
        await self._drop_button(folder, target)
        folder.fetch_msg_id = await self._bot.send_text(
            target, text, next_id=next_id, next_label=label
        )
        self._hold_button(folder, folder.fetch_msg_id, text, next_id)
        await self._storage.update_folder_state(folder)

    @staticmethod
    def _hold_button(folder: Folder, msg_id: int, text: str, next_id: int | None) -> None:
        folder.button_msg_id = msg_id if next_id is not None else None
        folder.button_text = text if next_id is not None else None

    async def _drop_button(self, folder: Folder, target: int) -> None:
        """Edit the current button holder (note or footer) so it loses its button."""
        if folder.button_msg_id is None or folder.button_text is None:
            return
        try:
            await self._bot.edit_text(target, folder.button_msg_id, folder.button_text)
        except TargetUnavailable:
            raise
        except GatewayError as exc:
            logger.warning(
                "folder {}: cannot drop button from {}: {}", folder.name, folder.button_msg_id, exc
            )
        folder.button_msg_id = None
        folder.button_text = None

    # ---- batches -------------------------------------------------------------

    async def _channel(self, channel_id: int, now: datetime) -> ChannelInfo:
        try:
            return await self._collector.channel_info(channel_id, now)
        except ChannelUnavailable:
            return ChannelInfo(
                id=channel_id,
                username=None,
                title=str(channel_id),
                subscribers=0,
                reactions_enabled=True,
                noforwards=False,
            )

    def _too_soon(self, folder: Folder, now: datetime) -> bool:
        if folder.last_batch_at is None:
            return False
        elapsed = (now - folder.last_batch_at).total_seconds()
        return elapsed < self._settings.auto_next_min_interval_s

    async def send_batch(self, folder_id: int, *, manual: bool = False) -> int:
        """Deliver the next batch of pending items. Returns how many were attempted.

        Automatic sends (read marker) re-check pacing under the lock, so two
        triggers that both passed the pre-check collapse into one batch.
        """
        async with self._lock(folder_id):
            return await self._send_batch(folder_id, manual=manual)

    async def _send_batch(self, folder_id: int, *, manual: bool) -> int:
        folder = await self._storage.get_folder(folder_id)
        if folder is None:
            return 0
        target = await self._storage.get_target(folder.name)
        if target is None:
            return 0
        cfg = folder.config
        now = self._clock()
        if not manual and self._too_soon(folder, now):
            return 0
        await self._storage.prune(folder.id, cfg, now)
        items = await self._storage.pending_items(folder.id, cfg.batch_size)
        if not items:
            return 0
        channels: dict[int, ChannelInfo] = {}
        for item in items:
            channel = channels.get(item.channel_id)
            if channel is None:
                channel = channels[item.channel_id] = await self._channel(item.channel_id, now)
            try:
                kind, last_id = await self._deliverer.deliver(target, item, channel)
            except (TargetUnavailable, SessionDead):
                raise
            except Exception:
                logger.exception(
                    "folder {}: {}/{} failed", folder.name, item.channel_id, item.msg_id
                )
                item.state = ItemState.FAILED
            else:
                item.state = ItemState.SENT
                item.delivery = kind
                item.sent_msg_id = last_id
                item.sent_at = now
            await self._storage.update_item(item)
        pending = await self._storage.count_pending(folder.id)
        sent = [i for i in items if i.state == ItemState.SENT]
        text = render_footer(sent, channels, cfg, pending)
        await self._drop_button(folder, target)
        next_id = folder.id if pending else None
        msg_id = await self._bot.send_text(
            target, text, next_id=next_id, next_label=f"Next {cfg.batch_size}"
        )
        self._hold_button(folder, msg_id, text, next_id)
        folder.fetch_msg_id = None
        folder.fetch_added = 0
        folder.last_batch_at = now
        await self._storage.update_folder_state(folder)
        return len(items)

    def _batch_read(self, batch: list[QueueItem], max_id: int) -> bool:
        """True once the read marker covers the configured share of the batch's posts."""
        seen = sum(1 for i in batch if i.sent_msg_id is not None and i.sent_msg_id <= max_id)
        needed = math.ceil(round(self._settings.auto_next_read_fraction * len(batch), 6))
        return seen >= max(1, needed)

    async def _next_due(self, folder: Folder, max_id: int, now: datetime) -> float | None:
        """Seconds until the next batch may go out: 0 for now, None when nothing is due."""
        if await self._storage.count_pending(folder.id) == 0:
            return None
        if folder.last_batch_at is None:
            return 0.0
        batch = await self._storage.batch_items(folder.id, folder.last_batch_at)
        if not self._batch_read(batch, max_id):
            return None
        elapsed = (now - folder.last_batch_at).total_seconds()
        return max(0.0, self._settings.auto_next_min_interval_s - elapsed)

    async def _kick(self, folder: Folder, target: int, now: datetime) -> None:
        """After a fetch: send a batch if the channel is idle (read), else wait for reads."""
        marker = await self._user.read_marker(target) if folder.last_batch_at is not None else 0
        wait = await self._next_due(folder, marker, now)
        if wait is None:
            return
        if wait <= 0:
            await self._send_batch(folder.id, manual=False)
            return
        self._schedule_recheck(folder.id, target, wait)

    def _schedule_recheck(self, folder_id: int, target: int, wait: float) -> None:
        if folder_id in self._rechecks:
            return
        self._rechecks.add(folder_id)

        async def recheck() -> None:
            self._rechecks.discard(folder_id)
            try:
                marker = await self._user.read_marker(target)
                await self.on_read(target, marker)
            except Exception:
                logger.exception("folder {}: deferred recheck failed", folder_id)

        self._defer(wait, recheck)

    async def _guarded_send(self, folder_id: int, *, manual: bool) -> None:
        try:
            await self.send_batch(folder_id, manual=manual)
        except SessionDead as exc:
            await self._bot.send_owner(f"💀 {await self._name(folder_id)}: user session dead: {exc}")
            self._fatal(exc)
        except TargetUnavailable as exc:
            name = await self._name(folder_id)
            logger.error("folder {}: digest channel unusable: {}", name, exc)
            await self._bot.send_owner(f"❌ {name}: digest channel unusable: {exc}")
        except Exception as exc:
            name = await self._name(folder_id)
            logger.exception("folder {}: batch failed", name)
            await self._bot.send_owner(f"❌ {name}: {exc}")

    # ---- triggers ------------------------------------------------------------

    async def on_read(self, channel_id: int, max_id: int) -> None:
        folder = await self._storage.folder_for_target(channel_id)
        if folder is None:
            return
        wait = await self._next_due(folder, max_id, self._clock())
        if wait is None:
            return
        if wait <= 0:
            await self._guarded_send(folder.id, manual=False)
            return
        self._schedule_recheck(folder.id, channel_id, wait)

    async def on_next_button(self, folder_id: int) -> None:
        await self._guarded_send(folder_id, manual=True)

    async def catch_up(self) -> None:
        """After a restart: a batch read while we were down still triggers the next one."""
        for folder in await self._storage.list_folders():
            target = await self._storage.get_target(folder.name)
            if target is None:
                continue
            try:
                marker = await self._user.read_marker(target)
            except SessionDead as exc:
                self._fatal(exc)
                return
            except Exception as exc:
                logger.exception("folder {}: cannot read marker", folder.name)
                await self._bot.send_owner(f"❌ {folder.name}: digest channel unusable: {exc}")
                continue
            await self.on_read(target, marker)

    # ---- config changes ------------------------------------------------------

    async def rescore(self, folder_id: int) -> int:
        """Re-score pending items with the folder's current strategy. Returns the count."""
        async with self._lock(folder_id):
            folder = await self._storage.get_folder(folder_id)
            if folder is None:
                return 0
            scores: list[tuple[int, int, float]] = []
            for item in await self._storage.pending_items(folder.id):
                cached = await self._storage.get_channel(item.channel_id)
                subscribers = cached[0].subscribers if cached is not None else 0
                scores.append(
                    (
                        item.channel_id,
                        item.msg_id,
                        score(item.engagement, item.views, subscribers, folder.config),
                    )
                )
            await self._storage.update_scores(folder.id, scores)
            return len(scores)
```

```python
def parse_run_args(args: list[str]) -> tuple[str | None, int | None, int | None]:
    """Trailing integers (up to two) are hours; the rest, joined, is the folder."""
    words = list(args)
    hours: list[int] = []
    while words and len(hours) < 2 and words[-1].lstrip("-").isdigit():
        hours.insert(0, int(words.pop()))
    folder = " ".join(words) or None
    from_h = hours[0] if hours else None
    to_h = hours[1] if len(hours) > 1 else None
    return folder, from_h, to_h


def parse_folder_args(args: list[str]) -> tuple[str, dict[str, str], bool]:
    """Split ``/folder`` arguments into (name, key=value pairs, off flag).

    The name is every word before the first ``key=value``; a trailing ``off`` with no
    pairs removes the folder. Raises ValueError on bad syntax.
    """
    words = list(args)
    name_words: list[str] = []
    while words and "=" not in words[0]:
        name_words.append(words.pop(0))
    pairs: dict[str, str] = {}
    for word in words:
        key, _, value = word.partition("=")
        if not key or not value:
            raise ValueError(f"expected key=value, got {word}")
        pairs[key] = value
    off = False
    if len(name_words) > 1 and name_words[-1] == "off":
        if pairs:
            raise ValueError("off takes no settings")
        off = True
        name_words.pop()
    name = " ".join(name_words)
    if not name:
        raise ValueError("folder name required")
    if name == "off":
        raise ValueError("'off' is reserved")
    return name, pairs, off


def apply_pairs(base: FolderConfig, pairs: dict[str, str]) -> FolderConfig:
    """``base`` with ``pairs`` applied; ValueError names an unknown key or the first bad value."""
    unknown = sorted(set(pairs) - set(CONFIG_KEYS))
    if unknown:
        raise ValueError(f"unknown key: {', '.join(unknown)}")
    data = base.model_dump()
    data.update({CONFIG_KEYS[key]: value for key, value in pairs.items()})
    try:
        return FolderConfig.model_validate(data)
    except ValidationError as exc:
        first = exc.errors()[0]
        field = ".".join(str(part) for part in first["loc"]) or "config"
        raise ValueError(f"{field}: {first['msg']}") from exc

def next_occurrence(value: str, now: datetime, tz: ZoneInfo) -> datetime:
    """``now`` itself, or the next wall-clock ``HH:MM`` in ``tz`` strictly after now."""
    if value == "now":
        return now
    try:
        at = time.fromisoformat(value)
    except ValueError as exc:
        raise ValueError(f"next: expected HH:MM or now, got {value}") from exc
    local = now.astimezone(tz)
    candidate = datetime.combine(local.date(), at, tzinfo=tz)
    if candidate <= local:
        candidate += timedelta(days=1)
    return candidate.astimezone(UTC)

            await self._storage.set_next_run(folder.id, next_run)
        changes = [
            f"{key} {fmt(next_run, self._tz) if key == 'next' and next_run else value}"
            f"{UNITS.get(key, '')}"
            for key, value in pairs.items()
        ]
        return f"✅ {folder.name}: {', '.join(changes)}"

    async def _create(
        self,
        name: str,
        cfg: FolderConfig,
        target: int | None,
        next_run: datetime | None,
        now: datetime,
    ) -> str:
        folder = await self._storage.create_folder(name, cfg, now)
        if target is not None:
            await self._storage.set_target(folder.name, target, now)
        if next_run is not None:
            await self._storage.set_next_run(folder.id, next_run)
        when = f"at {fmt(next_run, self._tz)}" if next_run is not None else "within a minute"
        return (
            f"✅ {folder.name}: every {cfg.period_h}h, posts "
            f"{cfg.min_age_h}–{cfg.min_age_h + cfg.period_h}h old, first fetch {when}"
        )

    # ---- the rest ------------------------------------------------------------

    async def _run(self, args: list[str]) -> str:
        name, from_h, to_h = parse_run_args(args)
        if from_h is not None and to_h is not None and from_h <= to_h:
            return "from_h must be greater than to_h"
        if name is None:
            folders = await self._storage.list_folders()
            if not folders:
                return NO_FOLDERS
            return "\n".join(
                [await self._service.fetch(f.id, from_h=from_h, to_h=to_h) for f in folders]
            )
        folder = await self._storage.find_folder(name)
        if folder is None:
            return f"unknown folder: {name}"
        return await self._service.fetch(folder.id, from_h=from_h, to_h=to_h)

    async def _status(self) -> str:
        folders = await self._storage.list_folders()
        if not folders:
            return NO_FOLDERS
        lines: list[str] = []
        for folder in folders:
            pending = await self._storage.count_pending(folder.id)
            fetched = (
                f"fetched {fmt(folder.last_fetch_at, self._tz)}"
                if folder.last_fetch_at is not None
                else "never fetched"
            )
            if folder.fetch_added:
                fetched += f" (+{folder.fetch_added} new)"
            batch = (
                f"batch {fmt(folder.last_batch_at, self._tz)}"
                if folder.last_batch_at is not None
                else "no batch yet"
            )
            line = (
                f"{folder.name}: {fetched} · queued {pending} · {batch} · "
                f"next {fmt(folder.next_run_at, self._tz)}"
            )
            if folder.last_error:
                line += f" · ⚠️ {folder.last_error}"
            lines.append(line)
        return "\n".join(lines)

    async def _list_folders(self) -> str:
        now = self._clock()
        titles = await self._user.list_folder_titles()
        lines: list[str] = [f"Telegram folders: {' · '.join(titles) or '(none)'}"]
        folders = await self._storage.list_folders()
        if not folders:
            lines.append(NO_FOLDERS)
            return "\n".join(lines)
        exclude = await digest_targets(self._storage)
        for folder in folders:
            lines.append(describe(folder, await self._storage.count_pending(folder.id), self._tz))
            try:
                channel_ids = await self._collector.source_channels(folder.name, exclude)
            except FolderNotFound:
                lines.append("  ❌ folder not found")
                continue
            for channel_id in channel_ids:
                try:
                    info = await self._collector.channel_info(channel_id, now)
                except Exception as exc:
                    lines.append(f"  {channel_id} · ❌ {exc}")
                    continue
                lines.append(f"  {info.title} ({info.display}) · {format_count(info.subscribers)}")
        return "\n".join(lines)

    async def _reset(self, args: list[str]) -> str:
        name = " ".join(args)
        if not name:
            return USAGE
        folder = await self._storage.find_folder(name)
        if folder is not None:
            name = folder.name
        result = await self._targets.reset(name)
        if result is None:
            return f"no digest channel mapping for {name}"
        if result.error is not None:
            return (
                f"reset {name}; ⚠️ old digest channel {result.channel_id} still in the folder "
                f"({result.error}); remove it by hand; next run creates a new one"
            )
        if result.removed_from_folder:
            return (
                f"reset {name}; old digest channel removed from the folder; "
                "next run creates a new one"
            )
        return f"reset {name}; next run creates a new one"
```

```python
"""Wiring: connect clients, build services, tick the folder schedules, serve forever."""

from __future__ import annotations

import asyncio
import sys
from collections.abc import Callable
from dataclasses import dataclass
from datetime import UTC, datetime, timedelta
from pathlib import Path
from zoneinfo import ZoneInfo

from loguru import logger

from .collector import Collector
from .commands import CommandHandler
from .config import Settings
from .delivery import Deliverer
from .digest import DigestService
from .storage import Storage
from .targets import TargetResolver
from .tg.bot import TelethonBot
from .tg.user import TelethonUser

HEARTBEAT_INTERVAL_S = 60
TICK_INTERVAL_S = 60


def configure_logging(level: str) -> None:
    logger.remove()
    logger.add(sys.stderr, level=level.upper(), enqueue=False, backtrace=False, diagnose=False)


def _utcnow() -> datetime:
    return datetime.now(UTC)


class Heartbeat:
    def __init__(self, path: Path) -> None:
        self._path = path

    def touch(self) -> None:
        self._path.parent.mkdir(parents=True, exist_ok=True)
        self._path.touch()

    async def run(self, interval_s: int = HEARTBEAT_INTERVAL_S) -> None:
        while True:
            self.touch()
            await asyncio.sleep(interval_s)


def latest_slot(next_run_at: datetime, period: timedelta, now: datetime) -> datetime:
    """Latest slot ``<= now`` on the grid ``next_run_at + k * period`` (k >= 0)."""
    if next_run_at > now:
        raise ValueError("not due yet")
    return next_run_at + (now - next_run_at) // period * period


class Ticker:
    """Every ``interval_s``: fetch each due folder, windowed on its latest complete slot.

    ``next_run_at`` moves to the slot after the one fetched, whether the fetch succeeded
    or not, so older missed slots are skipped and a broken folder retries next period.
    """

    def __init__(
        self,
        storage: Storage,
        service: DigestService,
        clock: Callable[[], datetime] = _utcnow,
        interval_s: float = TICK_INTERVAL_S,
    ) -> None:
        self._storage = storage
        self._service = service
        self._clock = clock
        self._interval = interval_s

    async def tick(self) -> list[str]:
        now = self._clock()
        results: list[str] = []
        for folder in await self._storage.due_folders(now):
            period = timedelta(hours=folder.config.period_h)
            slot = latest_slot(folder.next_run_at, period, now)
            try:
                results.append(await self._service.fetch(folder.id, at=slot, scheduled=True))
            except Exception:
                logger.exception("folder {}: scheduled fetch crashed", folder.name)
            finally:
                await self._storage.set_next_run(folder.id, slot + period)
        return results

    async def run(self) -> None:
        while True:
            try:
                await self.tick()
            except Exception:
                logger.exception("tick failed")
            await asyncio.sleep(self._interval)


@dataclass
class App:
    service: DigestService
    commands: CommandHandler
    ticker: Ticker


def build_app(
    settings: Settings,
    user: TelethonUser,
    bot: TelethonBot,
    storage: Storage,
    on_fatal: Callable[[Exception], None] | None = None,
) -> App:
    user.bot_username = bot.username
    collector = Collector(user, storage)
    targets = TargetResolver(user, storage, bot.username)
    deliverer = Deliverer(user, bot, settings.max_copy_bytes)
    service = DigestService(
        user=user,
        bot=bot,
        storage=storage,
        collector=collector,
        targets=targets,
        deliverer=deliverer,
        settings=settings,
        clock=_utcnow,
        on_fatal=on_fatal,
    )
    commands = CommandHandler(
        service, user, storage, collector, targets, ZoneInfo(settings.tz), _utcnow
    )
    return App(service=service, commands=commands, ticker=Ticker(storage, service, _utcnow))


async def _connect(settings: Settings) -> tuple[TelethonUser, TelethonBot, Storage]:
    settings.data_dir.mkdir(parents=True, exist_ok=True)
    storage = await Storage.open(settings.db_path)
    user = await TelethonUser.connect(
        settings.user_session, settings.tg_api_id, settings.tg_api_hash, settings.tmp_dir
    )
    bot = await TelethonBot.connect(
        settings.bot_session,
        settings.tg_api_id,
        settings.tg_api_hash,
        settings.bot_token,
        owner_id=user.me_id,
    )
    return user, bot, storage


async def run_once(
    settings: Settings, folder: str | None, from_h: int | None, to_h: int | None
) -> list[str]:
    configure_logging(settings.log_level)
    user, bot, storage = await _connect(settings)
    try:
        app = build_app(settings, user, bot, storage)
        if folder is None:
            return await app.service.fetch_all(from_h, to_h)
        found = await storage.find_folder(folder)
        if found is None:
            return [f"unknown folder: {folder}"]
        return [await app.service.fetch(found.id, from_h=from_h, to_h=to_h)]
    finally:
        await bot.disconnect()
        await user.disconnect()
        await storage.close()


async def serve(settings: Settings) -> None:
    configure_logging(settings.log_level)
    user, bot, storage = await _connect(settings)
    stop = asyncio.Event()
    fatal: list[Exception] = []

    def on_fatal(exc: Exception) -> None:
        fatal.append(exc)
        stop.set()

    app = build_app(settings, user, bot, storage, on_fatal=on_fatal)
    app.service.bind()
    bot.on_owner_command(app.commands.handle)
    await user.ping_bot(bot.username)
    await app.service.catch_up()
    logger.info("serving; folder schedules checked every {}s", TICK_INTERVAL_S)
    tasks = [
        asyncio.create_task(Heartbeat(settings.heartbeat_path).run(), name="heartbeat"),
        asyncio.create_task(app.ticker.run(), name="ticker"),
        asyncio.create_task(user.run_until_disconnected(), name="user"),
        asyncio.create_task(bot.run_until_disconnected(), name="bot"),
        asyncio.create_task(stop.wait(), name="fatal"),
    ]
    try:
        done, pending = await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)
        for task in pending:
            task.cancel()
        reason = "user session dead; run `telegrief login`" if fatal else "client disconnected"
        for task in done:
            if task.get_name() != "fatal" and task.exception() is not None:
                reason = f"{task.get_name()}: {task.exception()}"
        logger.critical("stopping: {}", reason)
        await bot.send_owner(f"💀 telegrief stopped: {reason}")
        raise SystemExit(1)
    finally:
        await storage.close()
```

````markdown
# telegrief

Ranked queue of Telegram channel posts from your folders. For every folder
you register with the bot, the service fetches, every `period` hours, the
posts published between `min_age` and `min_age + period` hours ago from every
channel in that Telegram folder, scores them by engagement (reactions per
view by default) and adds them to the folder's queue. Batches are delivered
into a private digest channel the service creates for you, best post first,
whichever fetch it came from; the next batch arrives once you have read most
(90%) of the previous one, or when you press **Next**. Posts wait in the
queue up to `max_age` days, so a few days away never cost you the best ones.

Design: `docs/superpowers/specs/2026-10-15-telegrief-design.md` and
`docs/superpowers/specs/2026-10-16-queue-design.md`.

## Requirements

- A Telegram **user account** (the service reads folders and channels as you;
  the Bot API cannot). Get `api_id` / `api_hash` at https://my.telegram.org.
- A bot token from @BotFather (the bot posts into digest channels and talks
  to you).
- Docker with compose.

## Setup

```bash
git clone git@github.com:ffoxin/telegrief.git && cd telegrief
mkdir -p secrets .data
echo 123456 > secrets/tg_api_id.txt
echo your_api_hash > secrets/tg_api_hash.txt
echo 123456:bot_token > secrets/bot_token.txt
docker compose pull
docker compose run --rm -it app telegrief login   # phone, code, 2FA once
docker compose up -d
```

Then open the bot chat and register a folder:

```
/folder Memes min_age=24 period=6
```

The first fetch happens within a minute; `/folders` shows the channels the
service resolved, `/status` the queue.

## Bot commands (owner only)

- `/folder <name> [key=value ...]` — add a folder (defaults apply) or change
  settings. Keys: `min_age` (hours, default 24), `period` (hours, default 24),
  `batch` (posts per batch, 10), `scoring` (`per_view` | `per_subscriber` |
  `raw`), `min_denominator` (floor for views / subscribers, 200), `max_items`
  (queue cap, 1000), `max_age` (days a post may wait, 7), `target` (use an
  existing channel id where the bot is admin), `next` (`HH:MM` in `TZ`, or
  `now`: when the next fetch runs). `/folder <name>` alone shows the settings.
- `/folder <name> off` — remove the folder and its queue; the digest channel
  stays.
- `/folders` — every folder with its settings, queue size, next fetch and the
  channels resolved from the Telegram folder.
- `/run [folder] [from_h] [to_h]` — fetch now; the window defaults to the
  folder's `min_age` / `period`, e.g. `/run Memes 24 0` for the last 24 hours.
- `/status` — last fetch, queue size, last batch, next fetch and the last
  error per folder.
- `/reset <folder>` — forget the digest channel and take it out of the folder;
  the next fetch creates a new one. The old channel itself is kept.
- anything else (`/start`, `/help`) — usage.

Folder names are matched ignoring emoji, case and extra spaces, so
`/folder mem period=6` finds the Telegram folder `😊mEm` and the digest
channel is titled after the real title with emoji removed (`mEm · digest`).
The service pins that channel at the top of the source folder (once; unpin
by hand if you like) and never reads digest channels as sources.

## How a fetch works

Every minute the service checks which folders are due. A due folder fetches
the window anchored to its scheduled slot, so a late run never leaves a gap;
if the service was down for several slots only the latest one is fetched.
New posts go into the queue (re-fetched ones are refreshed, already shown
ones are skipped), posts older than `max_age` are dropped, and the queue is
capped to the best `max_items`. The digest channel gets a short note
`📥 +N · M queued` (edited in place by later fetches until a batch goes out)
and, if the last batch is already read, the next batch right away.

A scheduled fetch that fails sends you one message per distinct error;
`/status` shows the last error until a fetch succeeds.

## Configuration
````
